# Python Data Structures and Sorting Algorithms

## Overview
This repository contains practical Python exercises focused on understanding and implementing sorting algorithms and data structures. It demonstrates how different sorting techniques work, how data can be organised, and how Python handles common programming tasks.

## Topics Covered

### 1. Sorting Algorithms
- **Bubble Sort:** Arranging elements by repeatedly comparing and swapping adjacent values.
- **Selection Sort:** Finding the smallest element and placing it in its correct position.
- **Merge Sort:** Dividing a list into smaller parts, sorting them, and merging them.
- **Quick Sort:** Sorting elements using a pivot and partitioning method.
- **Stable Sorting:** Maintaining the original order of elements with equal values.

### 2. Data Structures
- **Hash Tables:** Understanding key-value storage and hash-based operations.
- **Sets:** Working with unique elements and set operations such as union, intersection, and difference.

### 3. Practical Exercises
- Counting comparisons in Bubble Sort.
- Comparing the performance of sorting algorithms using sorted and reversed lists.
- Sorting M-Pesa-style transactions by amount in descending order.
- Preserving the original order of transactions with equal amounts.
- Testing solutions using Python assertions.
